# Aashish Sharma — Geospatial Portfolio

Responsive React portfolio with a Supabase-backed CMS.

## Features
- Public geospatial portfolio
- 60 CV records preloaded in Supabase
- Private admin dashboard
- Experience and project photo uploads
- Cover images and captions
- Reusable public photo gallery
- Published/draft controls
- Responsive mobile layout
- GitHub Pages deployment

Public content is stored in Supabase. Routine CV and gallery updates do not require editing React source.
